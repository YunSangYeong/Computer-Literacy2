# 문항 작성·검토 기록 — 1,000문항

컴퓨터활용능력 2급 필기 학습용. 작성·확인일 2026-10-19.

## 구성과 권리

| 과목 | 기존 개별 문항 | 새 개념형 | 조건 변형 | 합계 |
| --- | ---: | ---: | ---: | ---: |
| 컴퓨터 일반 | 30 | 160 | 310 (31유형×10) | 500 |
| 스프레드시트 일반 | 30 | 120 | 350 (35유형×10) | 500 |
| 합계 | 60 | 280 | 660 (66유형×10) | 1,000 |

모두 AI 일반 지식을 바탕으로 자체 작성했다. 원문 기출 0개·복원 0개다.
개별 작성 340개와 조건 변형 660개를 구별한다. 1,000개가 모두 서로 다른 개념이나
기출이라는 뜻은 아니다. 조건 변형 중 숫자 결과 590개, 문자 결과 70개다.
기존 60개에는 수치 결과를 묻는 12개와 문자·논리 함수 예제 등도 포함된다.
전체 집계 및 각 family의 수는 [bank-composition.json](bank-composition.json)에 있다.

다른 자격증 문제나 민간 CBT를 대량 복제하지 않았다. 문항 이용 조건은
Computer-Literacy2 contributors의 CC BY 4.0이며 LICENSE에 표시했다.
문항의 sourceUrl은 이 작성·검토 기록을 가리킨다. 저장소 주소는 작성 위치이며
개별 정답의 외부 증빙 자료 주소가 아니다. 연도·회차는 모두 null이다.

## 원고와 재현

- 기존 60개: `scripts/build_bank.py`의 COMPUTER/SPREADSHEET 원고
- 새 개념형 280개: `scripts/manuscripts/computer.tsv`, `spreadsheet.tsv`
- 조건 변형 660개: `scripts/expanded_bank.py`의 66개 유형과 고정된 각 10개 입력
- 생성: `python scripts/build_bank.py`
- 숫자나 순서를 무작위로 만들지 않는다. 동일 원고에서 동일 JSON·양식·집계가 생성된다.
- 기존 60개 객체 전체를 해시로 비교하여 ID·문제·보기·정답·해설·메타데이터 불변을 확인한다.
- 저장 namespace와 기존 ID를 바꾸지 않으며 이전 진행 시험·오답·북마크 복원도 검사한다.

새 개념형은 각 행의 관련 항목 4개를 서로 다른 보기로 사용한다. 각 항목의
설명과 보충 해설을 개별 원고로 작성했다. 새 문항의 `conceptGroup`은 관련 영역
분류이며 서로 다른 개념 네 개를 한 개념으로 세거나 네 개의 숫자 변형으로 세지 않는다.

## 검토 범위와 의미상 중복

새 개념 원고 전체와 계산 유형별 질문·보기·해설 문장을 내부 검토했다.
컴퓨터 일반은 Windows·시스템·자료 표현·입출력·네트워크·멀티미디어·보안 등을,
스프레드시트 일반은 Office 2021 환경에서 파일·입력·참조·함수·관리·분석·차트·출력 등을 다룬다.
법령 수치나 법률 해석 문제는 추가하지 않았다.

정규화한 본문·보기, ID의 기계적 중복을 검사한다. 조건 변형은 같은 개념을
반복하는 것이므로 의미상 유사성을 숨기지 않고 family로 묶는다. 모의시험은
동일 family를 우선 한 번만 선택하며, 개념형은 개별 ID로 선택한다.
기존 예제와 신규 유형 중 SUM·COUNT·참조 등 학습 개념이 겹치는 것은 의도된 반복이다.
개념형 중 COUNT/COUNTA·DNS/DHCP·복사/이동처럼 대비해 배울 항목은 함께 남겼다.
문제 수가 독립 개념 수를 뜻하지 않으며, 이 은행의 과목 내 구성 비율은 자체 학습 정책이다.

## 수치·함수 독립 검증

새 660개 전체는 `tests/expanded-bank.test.ts`에서 **표시되는 문제 본문을 파싱**하고,
원고 생성 코드(Python)와 별개의 TypeScript 식·필터·문자 연산으로 결과를 구한다.
저장된 exercise.inputs가 본문과 같은지, 기록된 expected와 실제 보기의 정답이 맞는지,
동치 보기가 하나뿐인지, 단위와 숫자/진법/문자 표시 형식이 맞는지 검사한다.
ROUND 계열은 Python Decimal과 별개의 정수 기반 소수 계산을 사용한다.
일반 공백을 다루는 문자 보기는 따옴표와 pre-wrap으로 실제 공백을 보존한다.

기존 15개 수치·문자·논리 예제의 별도 계산 검사도 유지한다.
단순 계산의 자동 검증과 해설 문장의 내부 검토는 구별한다. 실제 Excel 앱을
실행하여 660개 수식을 대조한 것은 아니며, 외부 전문가의 검수를 받지 않았다.
reviewed는 이 내부 검토를 마친 학습용이라는 뜻이다. imported 문항은 계속
pending으로 등록되고 사용자의 근거 입력 승인 전에는 학습에 포함되지 않는다.
