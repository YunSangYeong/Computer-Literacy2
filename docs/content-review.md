# 문항 작성·검토 기록

컴퓨터활용능력 2급 필기 학습용, 작성일 2026-10-19.

## 출처와 이용 조건

기본 60문항은 이 프로젝트에서 AI의 일반 지식을 바탕으로 새로 작성했다.
전기기능사 데이터와 민간 CBT의 문항을 복제하지 않았다. 원문 기출 0개, 복원 0개,
자체 제작 60개(컴퓨터 일반 30, 스프레드시트 일반 30), 숫자 조건 변형 0개다.
문항별 sourceUrl은 이 작성·검토 기록을 가리키며 외부 정답 증빙 URL이 아니다.
문항 이용 조건은 CC BY 4.0이며 저작자 표시는 LICENSE를 따른다.
원고 scripts/build_bank.py와 고정 ID CL2-C-001…030 / CL2-S-001…030을 보존한다.
난이도는 자체 학습용 분류이며 실제 시험 난이도 분석 결과가 아니다.

## 실제 검토 범위

모든 문항의 정답, 다른 보기 세 개, 해설의 표현을 작성 후 내부 검토했다.
컴퓨터 일반은 CPU/메모리/저장, 진법, 운영체제, 파일, 보안, 네트워크,
멀티미디어, 클라우드, 접근성의 기본 개념을 다룬다.
스프레드시트 일반은 셀 참조, 기초 함수, 정렬/필터, 차트, 서식, 인쇄,
피벗 테이블, 매크로 보안을 다룬다. 법령·규정 수치를 다루지 않는다.
공식 출제기준을 완전히 반영한 범위나 실전 기출 난이도라고 주장하지 않는다.

숫자 결과를 묻는 문항은 12개다(C-005, C-006, S-006…010,
S-012…015, S-017). 나머지 48개는 개념, 참조, 문자·논리 함수 등이다.
독립 재계산 테스트 15개는 위 12개와 S-011(IF), S-016(LEFT), S-021(AND)에
대해 원고 생성 코드와 별도인 JavaScript 계산·필터·문자 연산 경로로 정답 번호와
일치하는 보기가 하나인지 확인한다. 이는 실제 Excel 실행 검증이 아니다.
S-018(VLOOKUP)은 첫 열·정확 일치·반환 열의 의미를 문장 검토했고,
S-019/020은 Excel 오류와 IFERROR의 의미를 문장 검토했다.
상대/절대/혼합 참조 S-003…005는 복사 위치의 행·열 이동량을 대입하여 확인했다.

구조 검사는 모든 ID, 본문·보기 정규화 중복, 보기 4개, 정답 1…4,
자체 제작 연도·회차 null, 과목별 30개, 권리 표시를 확인한다.
의미상 중복은 주제와 의도 기준으로 내부 검토했으며, 예를 들어
COUNT/COUNTA, DNS/DHCP는 혼동하기 쉬운 서로 다른 동작을 구별하도록 남겼다.
외부 전문가 또는 별도 검수자가 검수한 것으로 표현하지 않는다.
reviewed는 이 내부 검토를 마친 학습용 문항이라는 뜻이다.

## 공식 자료 확인 상태

공식 시험 안내 후보:
https://license.korcham.net/co/examguide.do?cd=0103&mm=21

실제 HTTPS 요청은 프록시 CONNECT 403으로 차단되었다. 본문을 읽지 못했으므로
직접 확인한 출처로 인용하지 않는다. Microsoft 공식 도움말도 아직 읽지 않았으며
문항의 외부 검증 근거로 사용하지 않았다. 공식 기출 원문·정답·회차·재배포 조건은
확인되지 않았다. 공개 웹페이지라는 이유만으로 재배포 허용을 가정하지 않았다.

현재 학습용 잠정 규칙: 필기 컴퓨터 일반/스프레드시트 일반 각 20문항,
객관식 4지선다 총 40문항, 40분, 평균 60점 이상·각 과목 40점 이상.
앱 src/qualification.json의 rulesVerificationStatus는 pending이다.
실기는 구현 범위에 포함하지 않는다.

네트워크가 허용되면 공식 시험 안내와 현재 출제기준(적용 프로그램 포함)을
직접 대조하고, 확인한 URL·문구·적용일을 기록한 뒤 검증 상태를 갱신해야 한다.
실제 기출로 추가할 문항은 원문·공식 정답·회차 및 재배포 조건을 함께 확인해야 한다.
