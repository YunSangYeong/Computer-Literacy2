# 공식 시험 자료 대조 기록

확인일: 2026-10-19. 이번 작업에서는 HTTPS 요청이 성공하여 아래 자료를 실제로 읽었다.
이전 60문항 제작 당시의 CONNECT 403 기록과 구별한다.

## 대한상공회의소

- 안내: https://license.korcham.net/co/examguide.do?cd=0103&mm=21
- 위 안내의 첨부 `2024-2026년 컴퓨터활용능력 출제기준_202307(수정) .pdf`
- 첨부 경로: `/kor/etc/download.jsp?filename=2024-2026년 컴퓨터활용능력 출제기준_202307(수정) .pdf&cd=1`
- 받은 PDF SHA-256: `54e339f1cd0a09c431793c6f534d1a6b40520a99149e9840a5239c834d461388`
- PDF는 외부 자료로서 이 저장소에 재배포하지 않는다.

직접 확인한 핵심 규칙은 다음과 같다.

| 항목 | 확인한 내용 |
| --- | --- |
| 대상 | 컴퓨터활용능력 2급 필기 |
| 과목 | 컴퓨터 일반, 스프레드시트 일반 |
| 형태·시간 | 객관식 40문항, 40분 |
| 합격 | 매 과목 100점 만점에 과목당 40점 이상이고 평균 60점 이상 |
| 출제기준 적용 기간 | 2024-01-01 ~ 2026-12-31 |
| PDF 필기 기준 환경 | Windows 10, Microsoft Office 2021 |

과목별 20문항 및 보기 4개는 현재 앱의 학습 구성이다. 읽은 위 표에는 전체 40문항과
객관식이라는 표현이 있으며, 그 표만으로 세부 배분·보기 수를 직접 입증했다고 하지 않는다.
따라서 설정 상태는 `verified-core`로 기록한다. 실기 시험은 제공하지 않는다.
자료 적용 기간은 문서에 기록하며 메인에 학습 연도·자료 버전 선택 메뉴는 만들지 않는다.

PDF의 인쇄 페이지 23~25에 있는 2급 필기 항목을 읽어 운영체제·시스템 관리,
인터넷·멀티미디어·정보통신기술·보안, 스프레드시트 파일·데이터·계산·분석·차트·출력·매크로
영역과 원고를 대조했다. 2급 실기의 함수 목록도 보조 참고했으며, 이를 필기의 상세
출제 함수 목록으로 단정하지 않는다. 전 범위의 비중이나 실제 기출 난이도를 재현한 것은 아니다.

## Microsoft의 함수 설명

다음 페이지의 본문을 읽고 해당 쟁점을 확인했다. 이 네 자료를 전체 1,000문항의
개별 정답에 관한 외부 검증 증거로 확대 해석하지 않는다.

- TRIM: https://support.microsoft.com/en-us/office/trim-function-410388fa-c5df-49c6-b16c-9e5630b479f9
  - 일반 ASCII 공백(32)을 정리하고 단어 사이 한 공백을 남긴다.
  - nonbreaking space(160)를 TRIM 단독으로 제거하지 않는다.
- INT: https://support.microsoft.com/en-us/office/int-function-a6c4af9e-356d-4369-ab6a-cb1fd9d343ef
  - 작은 정수 방향으로 내리며 공식 예제 `INT(-8.9)=-9`를 확인했다.
- COUNTA: https://support.microsoft.com/en-us/office/counta-function-7dc98875-d5c1-46f1-9a82-53f3219e2509
  - 빈 문자열을 반환하는 수식도 비어 있지 않은 셀로 센다.
- COUNTBLANK: https://support.microsoft.com/en-us/office/countblank-function-6a92d772-675c-4bee-b346-24af6bd3ac22
  - 빈 문자열을 반환하는 수식도 세며 숫자 0은 빈 셀로 세지 않는다.

기출 원문·회차·공식 정답과 재배포 권한은 확보하지 않았으므로 기출·복원 수는 여전히 0이다.
